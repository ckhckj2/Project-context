# 6단계 — 분야별 퀴즈와 승급

2026-09-23 로컬 구현. 진입점 `app/index.html#/learn`. 운영 페이지 전환 및 배포는 하지 않았다.

## 성공 조건과 구현

- 도면·설계, 법규·인허가, 협업·전달의 성취를 독립 관리한다.
- 한 번에 한 문제를 보여주고, 답변 이후에 정답·이유·관련 업무 설명을 제공한다.
- 업무 설명을 읽고 같은 문제의 해설로 돌아갈 수 있다. 같은 문서에서 다른 화면으로 이동해도 입력·순서 선택·해설 상태를 유지한다.
- 연습은 성취를 올리지 않는다. 승급해도 기존 보기 깊이는 그대로이며, 획득한 범위 안에서 낮은 깊이로 돌아갈 수 있다.
- 진행 중인 풀이를 새 도전으로 덮어쓰지 않는다. 포기는 명시적 확인을 요구하고, 완료 결과에서는 다른 도전을 선택할 수 있다.

| 모드 | 문항 | 통과 | 결과 |
| --- | --- | --- | --- |
| 업무 중 연습 | 1 | 없음 | 성취 유지 |
| 짧은 연습 | 3 | 없음 | 성취 유지 |
| LV1→2, LV2→3, LV3→4 | 5 | 4개 이상 | 해당 분야만 +1 |
| LV4→5 | 8, LV1–4 목표 각 2개 | 7개 이상 | 해당 분야만 +1 |

강등, 시간 제한, 재도전 대기, 반복 탈락 패널티는 추가하지 않았다.

## 콘텐츠

`assessment-bank.mjs`는 분야마다 17개 목표와 목표당 2개 상황을 제공한다. 총 51개 목표, 102개 상황이다. 각 분야의 출제 수준별 목표 수는 5/5/5/2이다. 5지선다를 중심으로 순서 배열과 단답을 포함한다. 재도전은 두 상황을 번갈아 사용하며 무한 생성하지 않는다.

각 목표는 기존 `catalog.mjs`의 업무 ID와 같은 분야로 연결되며, 해당 업무 안내의 기준본·요청 범위·검토 조건·전달 승인 등 절차를 연습한다. 선택형 오답에는 선택 이유별 해설을 제공한다. `process-reviewed`는 이 프로젝트에서 절차 일관성을 검토한 표시이며 외부 전문가 인증이 아니다. 법정 수치나 최신 법 해석을 새로 단정하지 않는다. 정식 학습 콘텐츠 출시 전 실무 전문가 검토는 남아 있다.

기존 64문항과 기존 통합 성적은 변경하거나 세 분야에 복제하지 않는다. 새 학습 화면에서 기존 퀴즈로 이동할 수 있다.

## 책임 경계

- 콘텐츠: `src/content/assessment-bank.mjs`
- 출제·입력 검증·채점·진행 상태: `src/domain/assessment.mjs`
- 분야별 성취와 시도 소유권: `src/application/learning-session.mjs`
- 성취를 참조하는 보기 깊이: `src/application/reading-profile.mjs`
- 표시·입력 전달: `src/ui/learning-view.mjs`, `src/styles/learning.css`
- 경로 연결: `app/main.mjs`, 기존 navigation/execution 모듈

성취는 채점 소유자가 완료 결과로만 변경한다. UI가 점수를 제출하는 인터페이스는 없다. 입력 타입·길이·선택 ID·순서 중복을 검사하고, 외부로 내보내는 상태는 복사한다. 재제출·중복 완료·진행 중 덮어쓰기를 거부한다. 잘못된 데이터나 부족한 문제은행은 성공으로 처리하지 않는다.

## 검증

- `npm run check`: 기반 테스트 27개 및 기존 검사 27개 통과. 포맷·의존 경계·제한된 브라우저 기능·CSP 검사 통과.
- `check-learning-browser.cjs`: 실제 Chromium에서 세 응답 형식, 미입력 오류, 답변 복귀, 해설→업무→해설, 승급, 연습, 포기 취소/확인, 미통과, 320/390/768/1440 너비 확인. 저장소 접근을 차단한 상태에서도 동작하며 외부 요청·페이지 오류가 없다.
- `check-navigation-browser.cjs`, `check-reading-browser.cjs`, `check-execution-browser.cjs`: 연결된 기존 화면 회귀 검사.
- 실제 화면 캡처: `screenshots/stage-6/`. 모바일 문제·해설·결과와 PC 분야 선택을 검토했다.

## 보안 및 제한

새 네트워크 접근, 저장소 접근, 인증·권한, 라이브러리를 추가하지 않았다. 텍스트는 기존 안전한 DOM 도우미로 표시한다. 답은 학습용 클라이언트 코드에 있으므로 전문 자격 증명이나 부정행위 방지 시스템으로 사용할 수 없다.

새 성취·답변은 메모리에만 남아 새로고침 시 초기화된다. 화면에서 이를 명시한다. 영구 저장과 손상·충돌 복구는 7단계 범위다. 원격 CI 필수 검사와 배포가 활성화됐다고 간주하지 않는다.
