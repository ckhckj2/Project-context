# 인허가 3단계: 지역별 공식 확인 경로

2026-09-30. 인허가 안내에서 저장 프로젝트의 위치를 참고하며 조례·지구단위계획·특별계획구역 원문으로 이동할 수 있게 한다.

- ‘지역 기준 확인하기’ 한 개의 접힌 영역으로 추가한다. 주요 업무·검토 후보와 경쟁하는 파란 버튼을 늘리지 않는다.
- 저장 위치는 참고 정보로만 표시한다. 위치가 없거나 해외 주소·불완전한 주소여도 특정 관할이나 국내 법 적용을 추론하지 않는다. 공식 사이트에서 지역·지번을 직접 고른다는 점을 명시한다.
- 토지이음의 토지이용/도시계획, 자치법규정보시스템, 토지이음 고시정보를 연결한다. 대상 필지 → 관할 조례 → 결정·변경 고시와 결정도서 순으로 확인할 내용을 설명한다.
- 시행일·적용례·경과조치와 접수·승인 예정일을 대조하도록 안내한다. 검색 결과 없음은 비대상 판정이 아니며 누락된 결정도서는 관할청에 확인하도록 한다.
- 유형·시점 변경과 상세 안내 왕복에서는 펼침 상태를 유지한다. 저장 프로젝트가 바뀌면 위치를 새로 읽고 영역을 접는다.
- 위치·프로젝트명·규모를 URL, 외부 요청, 로그로 전송하지 않는다. 링크는 고정 HTTPS 주소이며 새 창에 `noopener noreferrer`로 연다. 새 입력·저장 키·권한·의존성은 없다.
- 기존 9종 검토 후보와 상세 법령 본문, 레벨, 저장 프로젝트, 개발 버전은 그대로 유지한다.

## 공식 경로 확인

2026-09-30에 페이지의 실제 기능과 URL을 확인했다. 개별 지역의 최신 적용 기준이나 특정 필지의 법적 상태를 검증한 날짜가 아니다.

- https://www.eum.go.kr/web/am/amMain.jsp — 주소·지번 기반 토지이용계획/도시계획 열람.
- https://www.elis.go.kr/main — 시·도/시·군·구별 자치법규 검색.
- https://www.eum.go.kr/web/gs/gv/gvGosiList.jsp — 지역·고시제목·고시일 등으로 결정·변경 고시 조회.

## 검증 범위

기본 검사와 배포 빌드, 기존 인허가 1·2단계 회귀, 새 영역의 키보드 조작과 6개 화면 폭, 위치 누락·특수문자·해외 위치·프로젝트 전환·상세 왕복, 저장 데이터 미변경 및 주소 자동 전송 없음. 실제 iPad/Safari 하드웨어 검증은 포함하지 않는다. 실행 결과와 원격 배포 완료는 PR/Actions에 기록한다.
