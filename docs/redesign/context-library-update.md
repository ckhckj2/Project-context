# 업무 맥락 정리와 독립 도면 가이드

2026-09-28. 기존 척척의 업무 선택·설명·레벨·프로젝트 저장 구조를 유지한다.

- 업무 맥락의 주요 버튼은 수행 순서, 목적·자료 두 개다. 담당자 질문은 사람 정보 옆에 두고, 프로젝트 주의사항은 기본 공개 문장으로 남긴다.
- 설계 단계와 프로젝트 전체 흐름은 같은 작은 위치 안내 영역에 상시 표시한다. 완료·승인 상태를 의미하지 않는다. 앞뒤 단계 버튼과 전체 흐름 펼치기 조작을 제거한다.
- 도면 가이드는 좌측 메뉴와 모바일 하단 메뉴에서 직접 연다. 계획·중간·실시설계의 공통 도면, 유형별 추가 확인, 납품범위 확인 순서와 수준별 안내를 보존한다.
- 도면 관련 업무의 준비자료 옆 링크는 해당 유형·단계를 도면 가이드에 전달한다. 도면 화면의 선택은 업무 설정이나 저장 프로젝트를 변경하지 않는다. 보던 업무로 돌아갈 수 있다.
- 완료된 단계 확인 배너의 시각적 강조를 낮춘다. 미확인 단계의 선택 과정과 주의 문구는 유지한다.

기존 콘텐츠 소유 파일과 view lifecycle을 사용한다. 새 검색 가로채기·저장 키·네트워크 요청·의존성·권한 변경은 없다. 도면 가이드 데이터 API는 기존 퀴즈와 공유한다.

검증: 기본 검사와 배포 빌드, 업무/레벨·검색·저장·퀴즈 회귀, 6개 화면 폭의 정렬과 overflow, 독립 도면 진입·단계/유형 변경·키보드·업무 왕복·저장값 보존. 최종 배포 상태는 PR/Actions에서 확인한다. 실제 iPad/Safari 기기 검증을 대신하지 않는다.

## 2026-09-29 현재 위치 보정

전체 흐름에 선택 단계가 없는데도 임의의 계획·동선 노드에 그 단계명을 붙이던 기존 동작을 수정한다. 일치하는 설계 단계가 있는 노드만 강조하고, 생략된 단계는 현재 위치로 꾸며 표시하지 않는다. 현재 설계 단계·앞뒤 단계는 상단 안내에 그대로 유지한다. 흐름 원문은 변경하지 않으며 실시계획 승인과 실시설계를 구분한다. 물류센터의 중간설계/실시설계, 결합된 중간·실시설계, 미정 단계와 상세 안내 반복을 회귀 검사한다.
