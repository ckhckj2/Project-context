# 4단계 — 업무 실행 흐름·조건·상세

2026-09-22. 기준 커밋 `7cd30b8`. 새 앱의 로컬 구현이며 운영 배포는 하지 않았다.

## 성공 조건과 범위

- 13개 지원 업무에서 실행 항목·완료 기준·자료·담당자·이유를 읽고 체크할 수 있다.
- 합의한 대표 경로인 도면 수정 → 보고서 반영 / 협력사 전달 → 도면·보고서 일치 확인을 선택으로 구성한다. 선택·상세 열기·체크·흐름 완료는 별도 동작이다.
- 선행 항목을 확인하기 전 후속 항목을 체크할 수 없다. 보고서와 도면의 확인이 합류하고 협력사 전달은 병행 가지로 남는다.
- 가지 제거·조건 변경·선행 항목 되돌리기는 영향 안내 뒤 명시적으로 적용한다. 관계없는 체크와 공통 메모를 보존한다.
- PC는 흐름 옆 상세 한 곳, 모바일은 상세 창 한 곳으로 표시한다. 심화 설명과 메모는 처음에 접어둔다.

`app/#/task/<id>`에서 첫 행동을 읽고 `업무 흐름 시작하기`로 `#/flow/<id>`에 진입한다. 기존 상세 안내는 보조 링크로 계속 제공한다. 전체 지원 태스크 사이의 관계를 임의로 만들어 자동 연결하지 않는다. 가지 추가는 콘텐츠 대응표에서 합의한 도면 수정 대표 경로에 제공한다.

## 책임과 연결

| 파일 | 책임 |
| --- | --- |
| `src/content/execution-guides.mjs` | 기존 work-rules의 13개 업무 문구·6개 단계 안내·변경업무 예외를 이전한 순수 데이터 |
| `src/content/execution-paths.mjs` | 대표 경로의 세부 노드·stable ID·선행 관계·허용 조건·필수 주의 |
| `src/application/execution-session.mjs` | 메모리 상태·명령 검증·영향 미리보기·가지/조건/체크/완료 전이 |
| `src/domain/workflow.mjs` | 기존 그래프 검증·체크·다음 업무·완료 판단을 그대로 재사용 |
| `src/ui/execution-view.mjs` | 안전한 DOM 표현·체크·상세·조건·확인 창 |
| `src/styles/execution.css` | 새 실행 화면에 한정된 반응형 표현 |
| `app/main.mjs` | hash 경로와 업무별 메모리 세션 연결 |

`report-update`, `consultant-send`, `document-match`는 기존 보고서 작성/협력업체 조정 태스크와 구분된 세부 노드다. 단계별 문구는 공통 데이터 한 곳에 두고 변경업무 예외만 분리했다. 신규 라이브러리를 추가하지 않았다.

## 데이터와 명령 규칙

- 같은 페이지의 hash 이동은 업무별 세션을 유지한다. 새로고침·새 문서 이동·탭 종료 뒤 복구되지는 않는다. 화면 상단에서 이를 안내하며 저장 성공으로 표현하지 않는다.
- 브라우저 저장소에 접근하지 않는다. 기존 프로젝트·레벨 키와 스키마를 변경하지 않는다. 영구 저장은 7단계다.
- 스냅샷은 깊은 복사이며 UI에서 바꿔도 원 상태는 변하지 않는다. 잘못된 ID·조건·체크 값·500자 초과 메모는 원 상태를 보존하고 거부한다.
- 같은 가지를 반복 추가해도 중복 노드를 만들지 않는다. 제거는 영향 노드/체크 수를 먼저 표시하며 재추가로 없어진 체크를 되살리지 않는다.
- 선행 항목을 되돌리면 연결된 후속 체크를 무효화한다. 보고서 항목을 되돌려도 협력사 전달 기록은 유지된다.
- 건물 종류·단계는 적용 버튼을 눌러야 바뀐다. 체크가 있으면 재확인할 업무와 개수를 알리고 다시 확인받는다. 선택 업무와 메모는 유지한다. 같은 조건을 재적용하면 체크를 지우지 않는다.
- 건물 종류는 참고 맥락이며 이 단계에서 시설별 법규 판단이나 승인 경로로 추론하지 않는다. 설계 단계는 기존 단계 안내·주의를 연결한다. `잘 모르겠어요`는 기본값/부정 답변이 아니라 미확정 상태다.
- 모든 항목을 체크해도 자동 완료하지 않는다. 사용자가 `이번 흐름 완료`로 확정하고 다시 진행할 수 있다. 학습 성취를 부여하지 않는다.


## 보안과 남은 사항

동적 문자열은 textContent/value 경로만 사용한다. 새 select/option은 공통 UI 태그 허용 목록에 추가했으며 값은 application에서도 검사한다. 신규 네트워크·저장 권한·파일 처리·외부 자산·API·로그 수집은 없다. 기존 CSP와 기존 운영 파일 예외 해시는 바꾸지 않았다.

기존 상세 안내에는 아직 새 UI로 이전하지 않은 시설/BIM/승인 경로별 정보가 남아 있다. 전체 분야·레벨 콘텐츠 이관은 5단계, 학습은 6단계, 내 업무 저장은 7단계다. 출처 원문을 보존했지만 최신 법규 검증을 수행한 것은 아니다.
원격 CI 활성화·배포 차단 설정·운영 전환은 별도 릴리스 작업이다. Safari 실기기·전체 스크린리더·실제 200% 브라우저 확대는 검증하지 않았다.
