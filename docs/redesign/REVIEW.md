# 1단계 검증 기록

검증일: 2026-09-16. 대상은 `preview/`의 독립 시안이다. 운영 코드 보안 감사나 제품 구현 완료를 의미하지 않는다.

## 완료한 확인

- 원본 13개 태스크와 64개 퀴즈를 대응표에 포함했다. 문항별 새 분야·레벨은 편집 검토가 필요한 초안이다.
- Chromium에서 390 / 768 / 1440px 너비의 홈·업무 흐름·학습 화면 가로 넘침을 검사했다.
- 업무 선택, 보고서 가지 추가, PC 측면 조건 편집, 모바일 조건 시트, 명시적 저장, 미완료 항목의 완료 차단, 전체 체크 후 완료, 다시 진행, 휴지통과 복원을 확인했다.
- 보기 깊이를 바꿔도 8개 완료 체크가 보존되는 것을 확인했다.
- 검색 입력을 HTML로 실행하지 않으며, 시나리오 중 외부 요청·localStorage 기록·JavaScript 실행 오류가 없었다.
- PC·모바일 캡처 7장을 생성하고 직접 확인했다. 모바일 흐름 범례 여백과 시트 폭을 조정했다.

## 재현

저장소 루트에서 실행한다. Node.js와 Playwright, 실행 가능한 Chromium이 필요하다. 검사 스크립트가 127.0.0.1:8765에 임시 서버를 시작하고 종료한다.

```sh
node docs/redesign/inventory.cjs
CHEOKCHEOK_BROWSER=/absolute/path/to/chromium node docs/redesign/check-preview.cjs
```

## 남은 범위

- 사용자 시각 검토와 분야·레벨 분류의 편집 확정.
- 실제 Safari/Android, 스크린리더·전체 키보드 동선, 확대·긴 콘텐츠의 제품 수준 검증은 구현 단계에서 진행한다.
- 대표 경로 이외의 본문, 실제 승급·저장·조건별 판단은 구현하지 않았다.
- 코드 책임 경계와 보안 검사의 CI 강제는 `architecture.md`의 2단계 작업이다. 현재 완료된 기능으로 해석하지 않는다.
- 이 시안의 단일 메모리 상태와 고정 경로는 화면 검토용이다. 제품 구조로 복사하지 않고 명시된 도메인·상태·화면 책임을 분리해 구현한다.
- 배포하지 않았다. 변경은 `docs/redesign/` 아래에만 있다.
