# 기존 척척 업무 맥락 정리 · 3단계

## 변경

기존 맥락 화면에서 업무 제목, 선택한 시설·설계 단계, 업무 목적을 먼저 읽도록 정리했다. 설계 단계의 이전·현재·다음은 접지 않고 표시한다. 단계 미상은 현재 위치를 추측하지 않고 선택 안내를 제공한다. 이 표시는 진행률·완료·승인 상태가 아니다.

지금 먼저 할 행동은 기존 상세 수행 순서와 같은 업무 모델에서 가져온다. 단계 맞춤/실제 수행 선택 이후에도 그 선택을 반영한다. 준비자료와 담당자는 보조 정보로 구분한다. 다섯 상세 기능은 동사가 있는 버튼으로 표시하고 수행 순서만 파랗게 강조한다. 다른 패널을 열어도 강조색이 중복되지 않는다.

Suno/Nea Studio의 Behance 제품 화면에서 확인한 중립색 바탕, 큰 제목, 여백과 구획, 제한된 행동 강조를 기존 척척에 맞춰 적용했다. 사진·차트·투자 UI를 복제하지 않는다. 맥락 화면의 반복 카드·그라데이션·아이콘은 줄이고 레벨 설명·전체 흐름·도면 안내·판단 사례는 기존 접기 기능으로 유지한다.

## 범위와 보존

- `context-renderer.js`: 업무명을 의미 있는 h1으로 변경.
- `v254_information_hierarchy.js`: 기존 위계 소유자에서 표시 순서·설계 단계 안내·업무 모델 기반 요약·명확한 버튼 이름을 처리.
- `app-components.css`: 기존 v254 소유 구간에 맥락 화면으로 한정한 스타일 적용. 검색 화면은 유지.
- `index.html`: 위 세 자산의 캐시 버전 변경.
- `tools/legacy-boundary.json`: 네 파일만 변경 사유와 해시를 개별 검토.

기존 상세 내용과 이벤트 컨트롤러, 5개 레벨, 마스터/낮은 레벨 미리보기, 퀴즈와 승급, 프로젝트와 메모, 검색 판정, 개발 버전 진입 명령은 유지한다. 단계 부적합 확인을 마치기 전에는 실행 버튼을 숨겨 기존 확인 절차가 우회되지 않도록 한다. 건축법상 용도 참고는 업무 안내 아래에 남긴다.

저장 키·형식, 인증·권한, 외부 요청과 의존성은 변경하지 않는다. UI에 선택한 값을 표시할 때 textContent를 사용한다.

## 검증 기준

- `npm run check`, `npm run build:site`.
- 기존 브라우저 회귀: 모든 5개 레벨/상세 패널 반복 열기, WHO 검색, 프로젝트 편집·생성·재접속, 특수문자·긴 값, 퀴즈·마스터 미리보기, CSP·외부 통신 없음, 손상/차단 저장소.
- 추가 실제 동작 검사: 항상 보이는 현재 단계, 단 하나의 파란 실행 버튼과 열린 보조 버튼 구별, 단계 미상/처음/마지막, 단계 맞춤·실제 수행 두 갈래, 첫 행동의 상세 모델 일치, 키보드 열기, 읽기 전후 저장 원문 동일성.
- 390/768/1440px 화면 육안 확인. 모바일 Safari/iPad 실기기 검사를 대신하지 않는다.
- 배포 산출물 검사 및 원격 Validate/Pages의 전체 브라우저 회귀를 통과한 뒤 운영 주소 확인.
