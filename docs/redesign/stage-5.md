# 5단계 — 분야별 설명 깊이

2026-09-23. 기준 커밋 `c26c937`. 로컬 구현이며 운영 사이트에는 배포하지 않았다.

## 성공 조건

- 분야는 도면·설계 / 법규·인허가 / 협업·전달의 3개로 유지한다. 탐색 분류 4개와 구분한다.
- 각 분야의 획득 레벨과 현재 보기 깊이를 분리한다. 획득 범위 안에서 LV1~5 중 낮은 화면으로 돌아갈 수 있다.
- 보기 변경은 업무 선택·체크·메모·조건·완료 상태·획득 레벨에 영향을 주지 않는다.
- 한 분야의 성취가 다른 분야의 상세 설명을 열지 않는다. 필수 주의와 실행 기능은 수준과 관계없이 사용할 수 있다.
- LV1~4에서 긴 설명을 누적하지 않고, LV5 전체 조율은 별도 창에서만 연다.

## 표시 방식

| 수준 | 기본/추가 정보 |
| --- | --- |
| LV1 큰 그림 | 현재 행동 한 개·완료 기준·업무 이유. 나머지 실행 항목은 한 곳에서 펼쳐 확인 |
| LV2 수행 방법 | 전체 실행 항목·준비 자료 |
| LV3 업무 연결 | 확인할 사람·현재 선택한 선행 업무 |
| LV4 조건과 판단 | 입력한 조건·미확정 조건·기존 단계별 판단 안내 |
| LV5 전체 조율 | 별도 창에서 선택 업무의 진행/대기·선행 관계 요약 |

상세 창의 `분야 · LVn 보기` 한 곳에서 설명 깊이를 바꾼다. 심화 설명은 처음에는 접혀 있다. 설명을 열어도 `살펴볼 내용` 선택으로 한 주제만 읽는다. 레벨이 높아졌다는 이유로 모든 설명을 펼치지 않는다.
LV1에서도 `다른 실행 항목 확인`으로 기존 체크를 되돌리거나 다른 항목을 읽을 수 있다. 모든 항목은 모델에 그대로 남는다. 현재 행동 체크 후 다음 행동으로 포커스를 옮긴다.
전체 조율은 다른 분야의 제목·작업 상태·선행 관계만 요약하며 해당 분야의 심화 본문을 우회 노출하지 않는다.

## 책임 분리

| 파일 | 책임 |
| --- | --- |
| `src/content/reading-levels.mjs` | 수준별 목표·연결 업무의 분야 |
| `src/application/reading-profile.mjs` | 분야별 획득 값 검증·보기 깊이·조회 복사본 |
| `src/application/execution-session.mjs` | 기존 실행 상태와 독립적인 읽기 프로필 연결 |
| `src/ui/reading-content.mjs` | 허용 주제 한 개 표시·전체 조율 요약 |
| `src/ui/execution-view.mjs` | 깊이 선택 창·LV1 현재 항목 우선 표시 |
| `app/main.mjs` | 여러 업무에서 같은 분야의 보기 선택을 공유 |

`createReadingProfile(earnedByTrack)`은 명시적으로 받은 분야별 값만 사용한다. 업무 완료에서 성취를 계산하거나 기존 통합 점수를 읽지 않는다. 획득 값을 변경하는 함수는 추가하지 않았다. `viewDepth`와 `visibleSections`의 기존 검증을 재사용한다.
프로필·보기 선택은 메모리만 사용한다. 같은 페이지에서 업무를 오가면 같은 분야의 마지막 선택을 유지하지만 새로고침하면 초기화된다. 영구 저장 연결은 7단계다.

## 실제 앱과 검토 화면

분야별 평가 연결 전인 실제 새 앱은 각 분야 LV1에서 시작한다. 기존 통합 레벨을 세 분야에 복제하거나 기존 저장값을 강등·덮어쓰지 않는다. 분야별 승급과 검증된 성취 연결은 6단계이며 아직 완료하지 않았다.

`docs/redesign/level-preview.html`은 실제 UI 모듈에 검토용 세 분야 LV5를 주입한다. 화면 상단에 **검토용·실제 성취 아님**을 표시한다. 검사와 디자인 검토용이며 배포 산출물에 포함되지 않는다. 새 앱에 상위 레벨을 부여하는 URL 옵션이나 임시 버튼을 넣지 않았다.

- `npm run check`: 신규/기반 테스트 21개와 기존 검사 묶음 27개 통과. 포맷·의존 경계·CSP·배포 산출물 검사 포함.
- `tools/check-reading-browser.cjs`: LV1~5/낮은 깊이 복귀, 주제별 노출, 상태·메모·조건 보존, 분야 분리, 전체 조율, 필수 주의, 320/390/768px 모바일 상세와 1440px PC 확인.
- `tools/check-execution-browser.cjs`: 기존 13개 업무·가지·선행 차단·조건 적용/취소·완료·재개·XSS 모양 메모·저장값 보존·저장소 차단 회귀 통과. LV1의 현재 항목 전환에 맞춰 실제 클릭과 체크 결과를 검증한다.
- `tools/check-navigation-browser.cjs`: 홈·검색·기존 상세·프로젝트/퀴즈 연결 회귀를 확인한다.
- `screenshots/stage-5/`의 모바일 LV1·PC LV1/LV4·전체 조율을 캡처해 직접 검토했다. LV4에서 설명 전체가 길어지는 문제를 확인하고 단일 주제 선택으로 수정했다.
- 새 검토 진입점도 CSP/로컬 자산 검사에 포함했다. 새 라이브러리·외부 통신·저장 권한·로그 수집을 추가하지 않았다.

이는 학습 정보의 표시 규칙이며 계정 인증/서버 권한 체계를 구현한 것은 아니다. 출처는 기존 업무 안내이며 최신 법규의 재검증을 의미하지 않는다.
