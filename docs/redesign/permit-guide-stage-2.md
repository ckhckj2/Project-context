# 인허가 2단계: 저장 프로젝트 조건 연결

2026-09-28. 1단계의 개략적인 검토 후보 안내를 유지하면서 저장된 프로젝트의 조건을 다시 입력하지 않도록 연결한다.

- 활성 저장 프로젝트의 시설 유형과 설계 단계를 기존 안내 범주에 연결한다. 홈 화면에서 임시로 고른 업무 조건은 저장 프로젝트를 대신하지 않는다.
- 프로젝트명과 조건의 출처를 표시한다. 위치·규모는 펼쳐 읽는 참고 정보이며 수치 판정, 지역 판정, 승인경로 추론에 사용하지 않는다. 누락된 위치·규모를 표시한다.
- 유형·시점을 직접 고르면 직접 선택한 조건임을 표시하고 저장 프로젝트 조건으로 돌아갈 수 있다. 상세 안내 왕복 시 선택을 유지한다.
- 저장 프로젝트를 전환하거나 수정한 뒤 안내로 돌아오면 변경된 조건을 읽는다. 프로젝트 기록, 기존 키, 레벨은 변경하지 않는다.
- 저장 데이터가 없거나 손상되거나 읽기가 차단돼도 직접 선택으로 안내를 사용할 수 있다. 손상된 데이터를 초기화하지 않는다.
- 복합시설·기숙사·박물관·도서관이라는 명칭만으로 주택사업 또는 공공발주라고 추정하지 않는다. 명시적인 범주 연결이 없는 유형은 ‘그 밖의 시설’로 둔다.

UI 파일은 v235_permit_reviews.js, 범주 연결은 review-rules.js, 화면 진입 갱신은 기존 app-runtime.js view lifecycle에서 담당한다. 새 저장 키·관찰자·검색 래퍼·외부 요청·권한 변경은 없다. 안내 법령 본문과 공식 근거 링크는 이번 단계에서 변경하지 않았다.

검증 범위: 기본 검사, 배포 빌드, 6개 화면 폭, 저장 조건·직접 선택·복원·상세 왕복·프로젝트 전환, HTML 입력 이스케이프, 데이터 미수정, 빈/손상/차단 저장소. 실행 결과와 배포 상태는 PR/Actions에 기록한다. 실제 iPad/Safari 기기 확인과 지역별 조례·특별계획구역 링크 연결은 별도 단계다.
