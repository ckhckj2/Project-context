# 인허가 4단계: 업무 맥락 연결

2026-10-05. 현재 업무에서 인허가 검토 안내를 열고, 보던 업무로 돌아오는 흐름을 연결한다.

## 변경

- 법규 검토·지구단위계획 조사·인허가 자료 작성·심의 보고자료 작성·변경업무 검토의 준비할 자료 아래에 ‘이 단계의 인허가 검토 보기’ 보조 링크 한 개를 둔다. 주 행동 두 개와 한 개의 파란 강조를 유지한다.
- 업무 맥락에서 열면 선택한 시설 유형·설계 단계를 넘긴다. 조건의 출처와 돌아갈 업무를 표시한다. 저장 프로젝트와 같은 유형이라는 이유만으로 위치·규모를 빌려오지 않는다.
- 안내의 유형·시점은 따로 바꿀 수 있고 ‘업무 맥락 조건 다시 적용’으로 복원한다. 원래 업무와 프로젝트 기록은 수정하지 않는다. 미정 단계는 전체 시점으로 표시한다.
- 기존 ‘내 업무 맥락으로 돌아가기’를 재사용하며 업무 선택·열린 상세 패널을 보존한다. 돌아오면 관련 링크로 키보드 초점을 복귀시킨다.
- 검색창에서 새로 인허가를 검색하면 저장 프로젝트 조건을 사용하는 기존 흐름으로 돌아간다. 레벨 변경에 따른 다시 그리기는 새 검색과 구분하여 조건을 유지한다.
- 9종 상세로 이동하는 검색어에 확인 의도를 명시하여 레벨 변경 시 용어 설명으로 바뀌지 않게 한다. 지역 기준 펼침 상태는 화면 교체 직전에 읽어 빠른 연속 조작에도 유지한다.
- 기존 LV3 인허가 실무 패키지도 같은 업무 맥락과 돌아가기 경로를 사용한다.

## 영향 및 유지

`v235_permit_reviews.js`, `app-runtime.js`, 관련 CSS와 캐시 키를 수정한다. 검색 분류 순서·법령 본문·후보 판단 규칙·레벨 정책·프로젝트 스키마는 유지한다. 새 저장 키, 외부 요청, 의존성, 권한은 없다. 사용자 표시값은 이스케이프하며 공식 확인 링크는 기존 고정 HTTPS 경로를 사용한다.

## 검증

기존 인허가 1–3단계와 도면 가이드 연결 회귀, 업무 왕복·열린 상세 보존·키보드 초점·저장 데이터 미변경·서로 다른 프로젝트 조건·직접 조건 변경 및 복원·미정 단계·레벨 새로고침·LV3 패키지를 브라우저에서 검사한다. 390/768/1024/1280/1440/1920px에서 넘침과 자료/협의 열 정렬을 확인한다. 첫 실행 항목은 전체 폭, 아래 자료/협의만 같은 행이라는 기존 위계를 유지한다.

`npm run check`, `npm run check:browser`, `npm run build:site`, `npm run build:release` 결과와 배포 상태는 PR/Actions에 기록한다. 실제 iPad/Safari 하드웨어 검증은 포함하지 않는다. 이 기능은 인허가 후보와 공식 확인처 안내이며 개별 프로젝트의 법적 대상 판정 기능은 아니다.
